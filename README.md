# Exercícios de Lógica de Programação - Algoritmos

Repositório com a resolução dos exercícios da apostila de **Lógica de Programação**, da **FIT - Faculdade de Informática de Taquara (FACCAT)**, implementados em **Java**.

## Sobre o projeto

Este repositório reúne exercícios desenvolvidos para praticar conceitos fundamentais de lógica de programação e algoritmos, utilizando a linguagem Java.
